# Cas d'utilisation de la première partie de l'API de géniALE

1. CU1 : Choisir sa plage de disponibilité
    1. Un membre ou un exec doit pouvoir s’identifier
    2. Aller chercher l’horaire
    3. Indiquer ses dates de disponibilité
    4. Sauvegarder sa sélection
    5. Se déconnecter
2. CU2 : Gérer un membre
    1. Un exec doit pouvoir s’identifier
    2. Aller dans la section gestion des membres
        1. Ajouter un membre ( nom, prénom, nom du programme, linkedin, photo, département )
        2. Supprimer un membre ( nom, prénom)
        3. modifier
    3. Sauvegarder alias envoyer
    4. Se déconnecter
3. CU3 : Gérer un évènement
    1. Un exec doit pouvoir s’identifier
    2. Aller dans la section gestion évènement
        1. Ajouter un évènement
        2. Supprimer
        3. Modifier
    3. Sauvegarder
    4. Se déconnecter
4. CU4 : Gérer les bières
    1. Un membre ou un exec doit pouvoir s’identifier
    2. Aller dans la section gestion bière
        1. Ajouter
        2. Supprimer
        3. Modifier
    3. Sauvegarder
    4. Se déconnecter
5. CU5 : Faire une notation de bière
    1. Un utilisateur va dans la section nos bières.
    2. Donne une notation avec un commentaire et un pseudo
    3. Envoie le formulaire
    4. Le site se met à jour
